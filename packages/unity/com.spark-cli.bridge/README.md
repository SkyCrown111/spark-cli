# SparkCLI Unity Bridge (Phase 14)

Placeholder package for Unity Editor ↔ SparkCLI WebSocket integration.

Planned capabilities (parity with Cocos `extensions/spark-cli-bridge`):

- Play Mode start/stop
- Selection query
- Console tail (warnings/errors)
- Scene open
- Lighting bake / Frame Debugger (via MCP engine tools)

Install by copying this folder into `Packages/com.spark-cli.bridge` or adding a local path in `manifest.json`.
